# NUMB — אתר תצוגה מקדימה

אתר סטטי (HTML/CSS/JS ללא framework, ללא build step) לתצוגה ואישור בלבד.
**נפרד לגמרי מהחנות הקיימת ב-Shopify (bynumb.com)** — אין חיבור, אין רכישה, אין סליקה.

## איך מריצים מקומית

אין תלות בשום דבר חוץ מדפדפן. כל שרת סטטי פשוט מספיק, למשל:

```bash
cd site
python3 -m http.server 8080
# פתחו http://localhost:8080
```

## מבנה

```
site/
  index.html      עמוד הבית — מותג + הדרופ הבא, אחר כך פריטים, אחר כך הסיפור שלנו
  catalog.html    קטלוג מלא: הדרופ הבא + ארכיון ("אזל מהמלאי")
  product.html    דף מוצר גנרי (?id=...), קורא נתונים מ-products-data.js
  about.html      עמוד קצר עלינו
  assets/
    css/style.css   כל מערכת העיצוב (טוקנים, קומפוננטות)
    js/main.js      תפריט נייד, סקרול-ריוויל, קטלוג/פילטרים, דף מוצר, טופס רשימת המתנה
    js/products-data.js   כל תוכן המוצרים — לערוך כאן, לא בתוך ה-HTML
    images/*.svg    תמונות placeholder — ראו רשימה למטה
```

כדי לערוך תוכן מוצרים (שם, קטגוריה, תיאור, תמונות) — לערוך רק את `assets/js/products-data.js`.
בכוונה **אין** בקובץ הזה מחירים, מידות, מפרטי בד, זמינות או תאריך השקה — אלה לא נמסרו, ולא הומצאו.

## מה זה "פריט ארכיון לדוגמה"

בקטלוג ובעמוד המוצר שלו מופיע פריט אחד בשם "פריט לדוגמה — דרופ קודם", מסומן `אזל מהמלאי`.
זהו **דמו בלבד** שממחיש איך ייראה ארכיון של דרופים קודמים עם סימון "אזל מהמלאי" — לא מוצר אמיתי.
יש להחליף אותו בפריטים אמיתיים מדרופים קודמים (ב-`products-data.js`, מערך `archive`), או למחוק את הערך אם זהו הדרופ הראשון של NUMB.

## רשימת תמונות נדרשת (IMAGE REQUEST)

כל התמונות באתר הן כרגע placeholder (ריבוע עם מסגרת אדומה וטקסט "תמונה חסרה") כדי שהעמודים ייטענו בלי שברי תמונה, ובכל אחת מצוין בדיוק מה צריך לצלם. להחלפה: שמרו קובץ **באותו נתיב ואותו שם**, בפורמט jpg/webp/png (רק תעדכנו את סיומת הקובץ ב-`src` אם היא שונה מ-`.svg`).

| קובץ | מידה מומלצת | מה לצלם |
|---|---|---|
| `assets/images/hero-campaign.svg` | פורטרט, לפחות 1600×2000 | צילום קמפיין ראשי לעמוד הבית — שחור-לבן, גדול, כזה שעובד גם בקאדר רחב (דסקטופ) וגם בקאדר גבוה-צר (נייד) |
| `assets/images/product-cap-1.svg` | 1200×1500 | כובע NUMB — זווית קדמית, רקע נקי |
| `assets/images/product-cap-2.svg` | 1200×1500 | כובע NUMB — זווית צד/תקריב (תפר, לוגו) |
| `assets/images/product-shorts-1.svg` | 1200×1500 | מכנסיים קצרים NUMB — קדמי, רקע נקי |
| `assets/images/product-shorts-2.svg` | 1200×1500 | מכנסיים קצרים NUMB — תקריב בד/כיס |
| `assets/images/product-shirt-women-1.svg` | 1200×1500 | חולצת NUMB לנשים — קדמי |
| `assets/images/product-shirt-women-2.svg` | 1200×1500 | חולצת NUMB לנשים — אחורי/תקריב |
| `assets/images/about-founders.svg` | 1400×1000 | תמונה של ניב, ליאון וליאל יחד |
| `assets/images/about-story.svg` | 1400×1000 | תמונת סטודיו/רחוב/מאחורי הקלעים לעמוד הבית ולעמוד עלינו |
| `assets/images/archive-sample-01.svg` | 1200×1500 | רק אם ממלאים תוכן ארכיון אמיתי — תמונה של פריט אמיתי מדרופ קודם |

**המינימום כדי לצלם רק פעם אחת:** אם יש רק תמונה אחת לכל פריט (בלי זווית שנייה), אפשר להשמיט את קובצי ה-`-2`
ולערוך את `products-data.js` כך שמערך `images` יכיל תמונה אחת בלבד לכל מוצר.

## מה יודגם אחרי אישור העיצוב

* חיבור תמונות אמיתיות (הרשימה למעלה).
* מחירים, מידות, מפרטי בד, זמינות ותאריך השקה — ברגע שיאושרו.
* קישורי אינסטגרם/טיקטוק אמיתיים (כרגע placeholder `#` בתפריט ובפוטר).
* החלטה נפרדת איך והאם להפוך את זה לחנות פעילה (Shopify או אחר) — לא נעשה כאן.
